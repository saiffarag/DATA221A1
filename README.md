# DATA221A1
# Assignment 1 – Introduction to Data Science

This repository contains solutions for Assignment 1.  
Each question is implemented in a separate Python file and can be run independently.

---

## Files Overview

### question1.py  
Multiplies consecutive integers starting from 1 until the product exceeds a specified threshold.  
Prints the final product and the integer that caused the threshold to be exceeded.

### question2.py  
Defines a function that takes a list of strings and returns a nested dictionary containing each string’s length and whether that length is even or odd.

### question3.py  
Defines a power function and applies it to a list of (x, y) pairs using argument unpacking.  
Skips pairs with negative exponents and prints the valid results.

### question4.py  
Generates random numbers between 0 and 1, sorts the list, and finds indices where values are greater than or equal to a randomly generated x value.  
Prints the sorted list, x, and the first matching index.

### question5.py  
Defines a function that validates two circle radii, computes their areas, and returns the percentage of the larger circle covered by the smaller one.  
Returns a message if invalid input is provided.

### question6.py  
Defines a function that analyzes a list of numbers and returns a dictionary showing the cumulative percentage of values less than or equal to each unique number.

### question7.py  
Defines a function that converts seconds since midnight into a formatted 12-hour time (HH:MM:SS AM/PM).  
Returns an error message for invalid input.

### question8.py  
Creates a Pandas DataFrame from given data, adds a computed column, and prints the final DataFrame.
